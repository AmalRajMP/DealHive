# DealHive – AI-Powered eCommerce Platform

DealHive is a full-stack eCommerce web application with AI-based features such as personalized recommendations and explainable outputs. The goal of this project is to combine web development with practical AI concepts in a real-world use case.

## Features

* Personalized product recommendations using AI
* Explainable AI (XAI) to show why products are suggested
* Chatbot support for basic user interaction
* Voice assistant integration (basic level)
* Responsive UI for mobile and desktop
* Dynamic data handling through APIs

## How to Run the Project

Clone the repository:

git clone https://github.com/AmalRajMP/DealHive.git
cd DealHive

Run frontend:

cd frontend
npm install
npm start

Run backend:

cd backend
npm install
nodemon server.js

Run AI service:

cd ai
python app.py
